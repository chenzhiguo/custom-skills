# Creative Tech Ad Prompt Generator (反差科技创意广告提示词生成器)

本 Skill 专门用于生成**“用苹果/特斯拉/英伟达顶级发布会手法，包装极其接地气事物”**的降维打击式创意广告视频提示词与全套视听脚本。

当前主要专注基于 **端到端声画一体生成（Audio-Video Co-generation）** 与 **中文自然语言驱动** 的先进工作流（如 MiniMax H3 / 海螺视频）。

---

## 核心设计法则（The Golden Rules）

1. **绝对严肃（Deadpan Dignity）**：通篇保持顶级旗舰产品发布会的肃穆、纯粹与从容，绝不嬉皮笑脸。反差感越强，喜剧冲击力越大。
2. **形态递进（Anti-Fatigue Progression）**：避免同类形态视觉疲劳，严格遵守“单体神秘外观 -> 内部解构/家族矩阵 -> 终极热能/功能相变”的形态演变。
3. **声画文四位一体（Multimodal Alignment）**：画面动作、浮空科技文字（HUD）、环境音效（SFX）、旁白（VO）必须严格按时间轴卡点对齐。
4. **冷幽默留白（Silent Punchline）**：旁白播音绝口不提俗气的价格，高冷收尾；真实接地气的价格（如“零售价 ¥1.50 起”）**仅以极简大字定帧静默浮现于画面角落**。

---

## 标准工作流（Step-by-Step Procedure）

当用户提出一个产品（如“生姜”、“洋葱”、“螺丝钉”、“辣条”、“搪瓷杯”）制作创意广告时，按以下步骤推进：

### 步骤 1：科技黑话映射（Jargon Mapping）
首先将该接地气事物的物理、化学与烹饪/使用特征，翻译为硬核科技术语。
参考速查字典：[jargon_dictionary.md](./references/jargon_dictionary.md)

* **产品命名**：`[事物名] Pro` / `[事物名] Ultra`（附带高端研发代号，如 Project ALLIUM）
* **外皮/包装**：仿生级天然全降解纳米防护壳 / 航天级发黑抗氧化装甲 / 纳米微晶硅酸盐覆膜
* **内部结构**：全固态高能储能矩阵 / 原生多核心分布式计算集群 / 芯片级微米晶圆架构 / 阿基米德精密变距螺旋
* **反应/使用**：高温热敏相变跃迁协议 / 动能物理冲击解构 / 极化生物活性穿透力场 / 毫秒级高压应力锁定
* **终极标语**：富有东方哲学或极简禅意的 5~7 字金句（如“与万味，皆相宜”、“微末之躯，紧系乾坤”、“野蛮张力，激活感官”）
* **反差报价**：接地气的真实零售价（如 ¥1.50 起 / 头，¥0.05 起 / 颗）

---

### 步骤 2：确定时长与结构形态（15秒经典三段式）

最标准、成片率最高的结构是 **15秒端到端一体化视频（3段 5秒无缝运镜）**：

* **0-5秒（外观悬念）**：纯黑深邃背景，单体反重力悬浮，激光全息扫描下扫，冷金双色边缘光。
* **5-10秒（内核解构/全系矩阵）**：
  * *硬核解构流*：沿轴向爆炸解构，数十片晶圆级半透明薄片/蒜瓣悬浮展开，全息HUD引线标注。
  * *全家福流*：白光闪烁转入纯白展台，大中小（Pro Max / Pro / mini）三颗家族舰队 360° 自转。
* **10-15秒（热态/功能相变与静默定帧）**：熟化金黄肉质炸裂 / 机械终极锁止，浓密微米级白色蒸汽逆光喷发，终极黑底大字定帧，旁白优雅收尾，价格静默出现。

---

### 步骤 3：音效与音色选择（Voice Persona Selection）

根据产品气质，从预设音色库中选择固定的声线档案：

#### 选项 A：【01号·科技发布会专属男声】（默认推荐）
* **音色设定**：35岁低沉磁性成熟男声，专业科技发布会/商业纪录片播音腔，近距离电容麦录音质感，低沉胸腔共鸣，语速沉稳从容（0.85倍速），全程同一个人发音。
* **适用场景**：土豆、大蒜、生姜、洋葱、板砖、螺丝钉等硬核科技或大地哲学风物。

#### 选项 B：【02号·极简高奢冷淡风女声】
* **音色设定**：28岁清冷知性女声，戴森/高端奢侈品香水广告质感，近距离微语调电容麦，语气沉静轻柔、克制内敛，呼吸感微弱，语速从容缓慢（0.85倍速），全程同一个人发音。
* **适用场景**：搪瓷杯、筷子、卷尺、辣条、板蓝根等日常物件被包装为艺术品或潮流轻奢品。

#### 选项 C：【03号·硬核工业澎湃男声】
* **音色设定**：40岁厚重沙哑力量感男声，超级工程/重工业大片质感，胸腔共鸣强烈，字正腔圆，威严霸气（0.85倍速）。
* **适用场景**：板砖、螺丝钉、老干妈、重装机械工具类。

* **语速字数标定**：5 秒视频对应 **12 ~ 15 个汉字**（预留 0.5s 前置音效 + 1.0s 尾音留白）。
* **音乐与音效控制**：一首连贯商业配乐贯穿始终，在最后报价格前音乐瞬间完全静音，只留清脆按键音。
